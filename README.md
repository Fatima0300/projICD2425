# Projeto ICD 2024/2025
 
# Análise dos Fatores Determinantes da Felicidade e Bem-Estar Emocional

Este estudo tem como principal objetivo analisar os fatores determinantes da felicidade e do bem-estar emocional utilizando métodos avançados de ciências de dados para analisar publicações científicas acerca do tema.

## Objetivo do Estudo

O estudo foi dividido em duas fases principais:

1. **Recolha de Artigos Científicos**:
   - Foram recolhidos artigos científicos do repositório **Scopus**.
   - Realizou-se uma análise bibliométrica utilizando a linguagem **Python** e os outputs do software **VOSviewer**.

2. **Processamento de Linguagem Natural (PLN) e Modelação**:
   - Foram aplicadas técnicas de **Processamento de Linguagem Natural** (NLP) para analisar o conteúdo dos artigos.
   - O objetivo foi identificar os fatores-chave que influenciam a felicidade dos indivíduos.

## Resultados Interativos

- **Dashboard Interativo**: 
  - Foi desenvolvido um **dashboard interativo** para a visualização dinâmica dos principais resultados da análise.
  - O dashboard oferece uma visão detalhada dos dados, facilitando a interpretação dos resultados encontrados.

## Contribuição Multidisciplinar

Este trabalho destaca a natureza **multifacetada da felicidade** e a abrangência do tema, demonstrando a importância de abordagens **multidisciplinares** para compreender algo tão complexo quanto a **mente do ser humano**.

## Tecnologias Utilizadas

- **Python**: Linguagem principal para análise de dados e bibliometria.
- **VOSviewer**: Software utilizado para visualização e análise bibliométrica.
- **Processamento de Linguagem Natural (PLN)**: Técnicas aplicadas para a análise de textos.
- **Dashboard Interativo**: Desenvolvimento de uma interface interativa para visualização de resultados.

## Como Executar o Projeto

Para garantir a reprodutibilidade e facilitar a execução do projeto, siga as instruções abaixo:

1. **Configuração do Ambiente**:
   - Crie um ambiente Conda com as dependências necessárias. Utilize o arquivo `environment.yml` para facilitar a instalação.
   
2. **Instalação das Dependências**:
   - Utilize o comando `pip install -r requirements.txt` para instalar as dependências listadas no arquivo `requirements.txt`.

3. **Execução do Código**:
   - Após a instalação das dependências, execute os notebooks Jupyter para explorar os dados e visualizar os resultados.

4. **Dashboard**:
   - O dashboard interativo pode ser executado localmente para explorar os resultados de forma dinâmica.
